Environment
Android SDK Platform 36 / Build Tools 35.0.0
Android Gradle Plugin 8.13.0 / Gradle 8.14.3 / Android Studio JBR 21.0.10
Package: com.theta.homehatch
Minimum Android API: 26 / target API: 35

Compilation
All three Java source files compiled successfully against the official Android
platform and lambda stubs, including the generated R classes.
This Windows sandbox rejects JDK ZipFS.toRealPath when closing archives.
The standard JavaCompiler API was therefore run in a short-lived process;
compilation returned true, then the process exited to release archive handles.
That invocation used Java 8 source/bytecode compatibility and Android boot classes.
Gradle used the resulting classes to dex and package the APK, with its duplicate
compileDebugJavaWithJavac task excluded. No compilation errors were ignored.

The source archive contains the conventional Gradle project and wrapper.
A normal development environment can use gradlew :app:assembleDebug.
The local test-signing key is retained in work/signing/hatch-alpha.keystore
outside the source ZIP so subsequent APK updates can use the same key.

Runtime/device coverage
No Android emulator or physical Android device was used during this build.
Z Fold5 display changes, S Pen, camera output, microphone service, widget
configuration, and tablet/Titan layouts still need device verification.

# 計画

## 核になる考え方（2026-10-23 の要望）

1. **背景（デスクトップ）はファイラー。** スマホはアプリへのアクセスは良いがファイルへのアクセスが悪い。PC のデスクトップのようにファイルの置き場をホームにする。ただし散らかして置くのではなく、ファイラーとして置く。
2. **端のタブでウィジェットを切り替える。** 予定・メール・連絡・ウィジェット・アプリ・リンク・Hatch などを、ファイラーの上にスライドインさせる。
3. 土台は ChatGPT 版 0.1.0。そこに要素を一緒に足していく。

## 足していく候補

0.2.0（Compose 版、コミット `e9728b4`）で作った部品を、ChatGPT 版に合わせて移植できるもの：

- [ ] ドロワーを端からスライドイン（今は本文と入れ替わる）。背景のファイラーは見えたまま
- [ ] ファイラーを常に背景に（今は狭い画面ではホーム、広い画面ではファイラー）
- [ ] フォルダのタブを自由に追加・名前変更・並べ替え（今は仕事・個人・写真の 3 つ固定）
- [ ] 予定・連絡先を一覧表示（今は各アプリを開くボタン）
- [ ] メール・LINE を届いた通知から表示し、押すと該当画面へ
- [ ] Hatch シリーズの登録済み一覧、導入済みの判定、GitHub Releases から取得・ハッシュ照合・インストール
- [ ] 共有メニューから受け取る Clip
- [ ] 物理キーボード（Titan）の Alt＋キー、打ち始めて検索
- [ ] ピン留めでドロワーを出しっぱなし（Fold5 メイン・タブレット）

## 実機で確かめること

ChatGPT 版の「はじめに.txt」にある項目（Fold5 の開閉、S ペン、ウィジェット設定、カメラ保存、録音の開始・停止、Alldocube・Titan の表示とキーボード）。

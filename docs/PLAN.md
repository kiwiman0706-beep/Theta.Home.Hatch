# 計画

## 核になる考え方（2026-10-23 の要望）

1. **背景（デスクトップ）はファイラー。** スマホはアプリへのアクセスは良いがファイルへのアクセスが悪い。PC のデスクトップのようにファイルの置き場をホームにする。ただし散らかして置くのではなく、ファイラーとして置く。
2. **端のタブでウィジェットを切り替える。** 予定・メール・連絡・ウィジェット・アプリ・リンク・Hatch などを、ファイラーの上にスライドインさせる。
3. 土台は ChatGPT 版 0.1.0。そこに要素を一緒に足していく。
4. **ファイラーから NAS へ行きやすく。** DSBooks のように、Tailscale と NAS の接続状態を表示する。つながっていなければ、Tailscale を開く・再接続するなどで助ける。
5. **ウィジェットは 1 タブに 1 つ。** タブにウィジェットを 1 つ格納し、大きさを変えられる。フォルダブルは閉じたときと開いたときでレイアウトが変わるので、ウィジェットの設定を画面ごとに持てるようにする。もう一方の画面の設定を持ってくるメニューも用意する。

## NAS と Tailscale（DSBooks の作りを参考に）

DSBooks（`kiwiman0706-beep/dsbooks`）での扱い：

- NAS には Synology の DSM File Station API で接続する。ログイン情報は端末内に保存する。
- Tailscale は外部アプリとして扱う。Tailscale アプリ（`com.tailscale.ipn`）を開く案内だけ行い、VPN を勝手にオンにはしない。
- VPN の有無は `NetworkCapabilities.TRANSPORT_VPN` で見る。ただし「VPN がない＝Tailscale がオフ」とは断定しない（NAS に届かない理由を、ネットワーク未接続・VPN オフ・NAS 側の問題に分けて案内する）。
- アプリに戻ったときや通信が回復したときに再確認する。ログインの期限切れのときだけ再ログインを求める。

Home Hatch での案：

- [ ] ファイラーの上部（またはタブ）に状態を表示：ネットワーク／Tailscale（VPN）／NAS の 3 つ
- [ ] つながっていなければ「Tailscale を開く」「再接続」ボタン
- [ ] NAS のフォルダをファイラーのタブに割り当て、階層を辿る・開く（開くときは端末に取得してから）

## ウィジェット：1 タブ 1 ウィジェット

- [ ] タブ 1 つにウィジェット 1 つ。タブを押すと、そのウィジェットがスライドインする
- [ ] ウィジェットの大きさを変えられる（ドラッグか、幅・高さの指定）
- [ ] 画面ごとの設定：Fold5 のカバー画面とメイン画面で別々に持つ（画面の幅で見分ける）
- [ ] 「もう一方の画面の設定を持ってくる」メニュー

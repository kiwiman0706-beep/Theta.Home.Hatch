# 経緯・ChatGPT 版との比較・次の一歩

作成：2026-10-23。

## 要望（原文の要点）

- Z Fold5 で使う。できれば Alldocube iPlay 60 / 80 Pro、Unihertz Titan 2 でも。
- 見た目はミニマルで綺麗でカッコいい。アイコンの羅列のホーム画面は嫌。
- カレンダー・連絡先・メール・LINE へのアクセスが良い。
- **ファイルやフォルダへのアクセスが良い（最重要）**。画面の端にタブがあり、フォルダが割り当てられていて、押すとフォルダがスライドインしてファイルに簡単にアクセスできる。
- タブにはカレンダーやメールのウィジェットを格納できる。ブックマークやアプリもドロワーで出せる。DeskHatch のように扱える。
- THETA.xxx.Hatch シリーズと連携し、入っていなければここから DL＆インストールできる。

4 本とも「アプリをまとめるフォルダ」はあっても、「実際のファイルが入ったフォルダを端のタブに結び付けて辿る」体験は無かった。ここがこのアプリの芯。

## ChatGPT 版 0.1.0-alpha をどう使ったか

ソースは [`reference/chatgpt-0.1.0-alpha/`](../reference/chatgpt-0.1.0-alpha)。

**仕様と部品はベースにした。コードは Kotlin＋Jetpack Compose で組み直した。**

| | ChatGPT 版 0.1.0 | この版 0.2.0 |
| --- | --- | --- |
| 構造 | Java の 1 ファイル（MainActivity 約 39KB、1 行に数千文字の行あり）。画面はすべてコードで組み立て | 役割ごとにファイルを分けた Kotlin。画面は Compose |
| 描き直し | 操作のたびに画面全体を作り直す（スクロール位置が戻る、ウィジェットも毎回作り直し） | 変わったところだけ描き直す。ウィジェットのビューは使い回す |
| ドロワー | 本文と入れ替わるだけ（スライドなし） | 端からスライドイン、なぞって開閉、ピン留めで横に並べる |
| フォルダ | 仕事・個人・写真の 3 つ固定 | タブの追加・名前・並び替え・削除が自由 |
| 予定・連絡先・メール・LINE | 各アプリを開くボタンのみ | 予定と連絡先を一覧表示。メールと LINE は届いた通知を並べ、押すと該当画面へ |
| Hatch | 名前と URL を手で登録 | シリーズ 10 本を登録済み。導入済みの判定、GitHub Releases の最新版確認、取得・ハッシュ照合・インストール |
| Clip | なし | 共有メニューから受け取る |
| 記録（録音・撮影・手書き・テキスト） | あり | 移植（手書きに消しゴム、録音は通知の停止ボタン） |
| ウィジェット | あり | 移植（並べ替えを追加） |
| ビルド | 本来のビルド手順の一部を外して作った APK、開発用の鍵 | 普通の Gradle ビルド、テスト・lint・画面の見本を CI で実行、専用の鍵で署名 |

ChatGPT 版から引き継いだもの：記録の 4 種類と保存の考え方（アプリ内保存＋書き出し）、筆圧とペン優先の手書き、ウィジェットの割り当て手順、既定のホームにする導線、黒×オレンジとグレーの 2 配色、アプリアイコンのモノクロ表示、仕事・個人・写真の初期タブ。

## 実機で確かめること

- [ ] Fold5：開閉でドロワーやフォルダの位置が保たれるか。メイン画面でピン留めが使えるか（幅 690dp 以上のときだけ出る）
- [ ] Fold5：Edge パネルのハンドルとタブが重ならないか（重なるなら設定でタブを左へ）
- [ ] フォルダ：Google ドライブを選んだときの読み込み速度、再起動後も許可が残るか
- [ ] 予定・連絡先・通知の許可の流れ
- [ ] LINE の通知を押して該当トークが開くか（Android 14 以降）
- [ ] ウィジェット：割り当て許可と設定画面、大きさ
- [ ] 記録：録音の開始・停止、カメラの保存、S ペンの筆圧と手のひらの無視
- [ ] Hatch：インストール確認画面まで進むか、更新の判定
- [ ] Titan 2：Alt＋キー、打ち始めて検索、タブのスクロール
- [ ] iPlay：横向きで 2 枚並べたときの幅

## 次の一歩（案）

1. 実機確認の結果を 0.2.x で直す。
2. 画像のサムネイル、広い画面ではファイル一覧の横にプレビュー（ChatGPT 版にあった機能）。
3. ホーム以外の画面でも端のタブを出す（他アプリの上に重ねる権限が必要。第 2 段階）。
4. Gmail API で受信一覧（今は届いた通知のみ）。
5. Theta Vault との連携（Vault のフォルダをタブに、各 Hatch の「最近」を Widget のように）。
6. GitHub Releases での配布と、このアプリ自身の更新確認。

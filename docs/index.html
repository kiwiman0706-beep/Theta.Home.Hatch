ICON // 3-TONE

アイコンを 3 色に

VOICE // LAUNCH

[ DEVICES ]

画面の幅で形が変わる

端末幅背景ドロワー
Galaxy Z Fold5（閉じた画面）・Titan 2600dp 未満ダッシュボード（今日の予定・天気・つながり・ファイル・端末）重ねて出す

[ INSTALL ]

入れ方

  1. Releases から ThetaHomeHatch-<版>.apk を入れる（提供元不明のアプリの許可が要ります）
  2. 普通のアプリとして開き、フォルダのタブにフォルダを割り当てる
  3. 画面上部の「HOME 未設定」から、既定のホームにする
  4. 以後は画面上部の「UPDATE」から更新（1 時間ごとに確かめます）
  5. 欲しい機能は「REQUEST 依頼 ↗」から
PRIVACY

通知・連絡先・予定は端末の中だけで使い、送りません。NAS のパスワードと Gemini の API キーは端末の鍵で暗号化して保存します。外へ送るのは、自分で使うと決めたもの（Gemini へのアイコン画像、天気のおおよその位置、Google ドライブの読み取り）だけです。

[ RESCUE ]

ベータ版でも詰まない

クイック設定のタイル

通知パネルの「ホームのレスキュー」。本体と別のプロセスで動くので、ホームが固まっていても開けます。

自動でレスキュー画面

起動してすぐ止まるのが続いたら、ホームの代わりにレスキュー画面。別のホームを選ぶ・セーフモード・最新版を入れる。

固定の START

端のタブのいちばん下に、いつでも全アプリを開ける START。タブを全部外しても詰みません。

# Theta Home Hatch 0.40.0-alpha

- **ダウンロード（Download）のフォルダを、タブやホームのファイラーに置けるようにしました**
  - Android 11 以降は、フォルダを選ぶ画面で Download（とストレージのいちばん上）を選べない決まりなので、ホームが端末の Download を直接読むようにしました
  - 置き方
    - 端のタブの「＋」→「**＋ ダウンロード**」（DOWNLOAD のタブができます）
    - ふつうのタブの歯車 →「＋ 足す」→「**＋ ダウンロード（Download）**」
    - フォルダを 1 つ置いたタブの長押し →「**ダウンロード（Download）にする**」
  - 初めに、端末の「**すべてのファイルへのアクセス**」をこのホームに許可します（タブの中の案内のボタンから。読むだけで、ファイルを送ったり集めたりはしません）。許可して戻ってくると、すぐ読み直します
    - 「制限付き設定」と出たら、アプリ情報の右上の「︙」→「制限付き設定を許可」をしてから
  - フォルダが先、ファイルは**新しい順**に並びます。中のフォルダにも入れます。ホームのファイラーの「場所」にも出ます
  - 押すと中で開く（画像・PDF・動画など）か、ほかのアプリで開きます。長押しで共有・ピン留めも

実機での確認はまだです。

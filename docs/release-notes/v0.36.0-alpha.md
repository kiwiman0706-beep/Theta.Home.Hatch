# Theta Home Hatch 0.36.0-alpha

## テーマを 5 つ追加（設定 → 見た目 → THEME）
色を変えるだけでなく、区画の枠・見出し・時計・アイコンの台・影・背景の模様・書体まで変えます。

- **TERMINAL（緑の端末）**：黒地に蛍光の緑。区画の見出しは反転した帯、文字は全部等幅、背景に流れる文字の列。時計は反転した日付の帯と大きな等幅の数字
- **BRAUN（白い家電）**：生成りの地にオレンジ 1 色。**めくり時計**（暗い 2 枚の板）と丸い日付の文字盤、浮き出た角丸の台、アイコンは丸い台
- **SOFT（浮き出し）**：線を使わず、影で台が浮き出ます。大きな角丸、淡いオレンジ・青・緑
- **WINDOW（昔のパソコン）**：水色の地に白い方眼。区画もドロワーの見出しも**オレンジのタイトルバーに「_ □ ×」の窓**、太い線と右下の影。時計は「Clock.exe」の窓
- **LCD（液晶ゲーム機）**：くすんだ黄緑の地に濃い緑の太い線、全部等幅、液晶の数字の時計、画素の細い横線

## Gemini のアイコンをテーマに合わせて
- 描き直しの頼み方（プロンプト）を 4 つに分けました
  - 計器盤のステンシル（ダーク・ライト・ALERT・SCI-FI）：今までどおり
  - **ドット絵**（TERMINAL・LCD）：粗い格子の 1 ビット風
  - **丸くかわいい**（POP・SOFT・WINDOW）：太い縁の丸いステッカー風
  - **細い線の家電ふう**（BRAUN）：円と角丸と細い線だけの静かな記号
- 描き方ごとに別に保存します。テーマを切り替えて「加工する」を押すと、そのテーマの描き方で作ります（1 アプリ 1 回ずつ）。まだ作っていない描き方では、計器盤のものを代わりに出します
- 色はこれまでどおり、テーマの色で塗ります

実機での確認はまだです。

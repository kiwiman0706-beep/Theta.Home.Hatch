# Theta Home Hatch 1.16.0

- **端末の写真・動画のタブ**を作れます
  - 端の「＋」→「＋ 写真・動画（端末）」
  - フォルダを選ばずに、端末の中の画像と動画を全部、新しい順に並べます（ギャラリーと同じ。フォルダを選ぶ画面では選べない場所も入ります）
  - いちばん上の「アルバム」から、カメラ・スクリーンショット・ダウンロードなど、アルバムごとにも見られます
  - 今あるフォルダのタブも、長押し →「端末の写真・動画（すべて）にする」で切り替えられます。ふつうのタブの「＋ 足す」にもあります
  - Download と同じく「すべてのファイルへのアクセス」の許可を使います（許可済みならそのまま）

# Theta Home Hatch 0.35.0-alpha

## ホーム（タブではないところ）
- 時計・検索・予定・通知・天気・つながり・ファイルへの入口・**ファイラー**・端末を、**区画**として並べるようにしました
- 設定 →「HOME / ホームの並び」で
  - ▲▼ で順番
  - 「閉」「開」で、閉じた画面（カバー）・開いた画面（メイン・タブレット）に出すか
  - 「左」「右」で、2 列のときの列
- **開いた画面・横長のタブレットでは 2 列**（初めは左に時計・予定・通知・天気など、右にファイラー）。2 列は切ることもできます
- ファイラーも区画の 1 つです。閉じた画面では初めは出さず、「ファイルへの入口」の NAS・DRIVE・最近を押すと全面で開きます

## タブ
- タブはフォルダ・アプリ・ウィジェットなどを**ポップアップで出すもの**、という位置づけにしました
- ホームの「ファイルへの入口」でフォルダを押すと、ファイラーではなく**そのタブ**が開きます
- **タブを両側に置けます**（設定 →「見た目」）：「開いた画面だけ両側」（初め）・「いつも片側」・「いつも両側」
  - 両側のときは、アプリのカテゴリーのタブが START の反対側、ほかのタブが START の側
  - タブを長押し →「右側へ移す」「左側へ移す」で 1 つずつ変えられます
  - 反対側に置くタブが無ければ、その側の端は出しません
- **エッジ**（ほかのアプリの上に出すタブ）は、**タブだけ**を出すようにしました（前に開いていたタブを自動で開かない）

## そのほか
- **初めて入れたときの案内**：「前の設定を読み込みますか」→ 読み込まないなら「アプリを仕分けしますか」と聞きます（更新したときは出ません）
- **Hatch のアプリ一覧**：設定のいちばん下「HATCH / Theta Hatch シリーズ」から、ほかの Hatch のアプリを入れる・更新する・開くことができます。Theta Memo Hatch・キッズホーム・Theta Hitsudan Hatch（PC 用）を一覧に足しました

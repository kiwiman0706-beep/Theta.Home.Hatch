# Theta Home Hatch 0.11.0-alpha

## 狭い画面はダッシュボードに
閉じた Fold5・Titan など（幅 600dp 未満）の背景を、ファイラーからダッシュボードに変えました。
- 今日の予定（全部。終わったものは薄く）
- 天気（Open-Meteo・API キー不要）：今の天気・体感・湿度・風、24 時間、7 日。場所は現在地か地名で
- つながり（NET・Tailscale・NAS）
- ファイル：場所のボタンと最近開いたファイル。押すとファイラーが開き、✕か戻るでダッシュボードへ
- 端末：電池・空き容量

広い画面は今までどおりファイラーで、上部が「TODAY'S_EVENTS」（今日の予定）になりました。

## カレンダー
- 月・週・日を切り替え。左右になぞって前後へ、TODAY で今日へ、＋で予定を追加
- 月は日曜始まり。予定は何件あっても全部出します（週の行が予定の数に合わせて伸びる）
- 日は時間割。重なる予定は横に並べ、今の時刻に線

## カテゴリーのタブに通知
- そのカテゴリーのアプリに届いている通知を、アプリの下に並べます（通知へのアクセスの許可が必要）
- アイコンに通知の件数

実機での確認はまだです。

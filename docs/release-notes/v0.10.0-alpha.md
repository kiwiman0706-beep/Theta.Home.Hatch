# Theta Home Hatch 0.10.0-alpha

## タブ
- 端のタブの「＋」を「タブを追加」に。ウィジェット・アプリのカテゴリー・フォルダ・ドロワー（外したもの）から選べます
- タブを長押し：上へ・下へ・いちばん上へ・名前を変える・外す（ウィジェットのタブも同じ）

## ウィジェットの追加
- 許可や設定画面で止まったときに、理由を表示するように
- 設定画面を開けないウィジェットは、設定なしで置く
- ウィジェットだけのアプリも一覧に出るように

## アプリ
- アプリの一覧はタブから外し、検索の横のボタン（Alt＋A）で開くように（タブに戻すときは「＋」から）
- アプリのカテゴリーをタブにできるように。初めはアイコンのグリッド
- アプリの一覧にも、一覧／グリッドと大きさ 4 段。全体とカテゴリーのタブごとに覚えます

実機での確認はまだです。

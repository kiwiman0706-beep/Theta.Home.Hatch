# Theta Home Hatch 0.28.0-alpha

## 「タブを出す」ショートカット
ほかのアプリを使っているときに、端をなぞったときと同じタブを今のアプリの上に出せます（エッジがオフでも使えます）。
- **Dimple など**ショートカットを置けるアプリ：このアプリの「タブを出す」ショートカットを選びます（アイコンの長押しにも出ます）
- **Galaxy のモードとルーチン**など、アプリを開くことしかできないもの：「アプリを開く」で、アプリの一覧の「タブを出す」を選びます
- 自動化アプリからは、アクティビティのアクション `jp.yaegaki.theta.home.SHOW_TABS` でも呼べます
- アプリの一覧の「タブを出す」が要らなければ、設定 → SHORTCUT で隠せます

## カテゴリーのタブにもウィジェットなど
カテゴリーのタブの見出しの歯車から、アプリの上にウィジェット・フォルダ・画像・Web ページ・予定・通知などを置けます。アプリと一緒にスクロールし、高さ・幅（全幅／半分）・並びを決められます。

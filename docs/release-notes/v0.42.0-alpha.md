# Theta Home Hatch 0.42.0-alpha

- **START（すべてのアプリ）を開くと、絞り込みの欄に合うように**しました。キーボードが出るので、そのまま打てばすぐ探せます
  - 声で開いたとき（START の長押し・「声でアプリ」）と、カテゴリーのタブでは合わせません
- **スタートにピン留め**
  - アプリ・ショートカットを長押し →「**スタートにピン留め**」で、START のいちばん上の「START」の欄に**大きなアイコン**で並びます
  - 並んだものを長押しで「◀ 前へ」「▶ 後ろへ」「スタートから外す」
  - 端の下のピン留め（8 つまで）とは別です。長押しのメニューは「スタートにピン留め」「端の下にピン留め」の 2 つになりました
  - START のピン留めがあるときは、START の中に出していた端の下のピン留めの列は出しません（端の下にはそのまま）
  - 設定の書き出し・読み込みにも入ります

実機での確認はまだです。

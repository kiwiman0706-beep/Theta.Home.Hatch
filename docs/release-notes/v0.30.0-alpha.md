# Theta Home Hatch 0.30.0-alpha

- **入力**：ピン留めの「入力」（ペンのアイコン）から、声・文字・写真で書いて、そのまま送れます
  - 送り先：LINE・メール・ほかへ共有・Clip・メモだけ
  - どれを押しても、先に **MemoHatch に残します**（入っていなければこのホームの Clip。「送り先…」で切ることもできます）
  - 「送り先…」で並びと、**LINE の決まった宛先**（最近の会話から）を選べます。宛先を決めて送るのは試しの機能で、LINE が受け付けないときは LINE の送り先を選ぶ画面になります
  - 前からピン留めを決めていた場合も、一度だけ先頭に足します（外したら戻りません）
- **回線の速さ**：上の帯に、下りの速さと応答時間を出します。初めは 30 分おき（設定の NETWORK で 15・30・60 分・切る、モバイル回線では測らない設定も）。押すとすぐ測ります
- **再接続**：つながらない・遅いときにボタンが出ます
  - アプリからはモバイルデータを直接切り替えられないので、Galaxy のモードとルーチンなどで「モバイルデータを切って入れる」ルーチンを作り、そのショートカットをホームに置くとき「再接続ボタン」を選んでください。ボタンがそれを動かします
  - 置いていなければ、Android に「つながらない」と知らせて、インターネットの切り替えパネルを開きます

実機での確認はまだです。

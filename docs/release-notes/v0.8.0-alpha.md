# Theta Home Hatch 0.8.0-alpha

## ファイラー
- サムネイル（写真・動画・PDF。NAS と Google ドライブも）
- 一覧／グリッドの切り替えと、大きさ 4 段（S・M・L・XL）。一覧の右上のボタンで
- 見せ方はフォルダごとに記憶。設定の無いフォルダは親フォルダの見せ方を引き継ぐ。写真・動画が多いフォルダは初めからグリッド

## Google ドライブ（新規）
- Drive API でつなぐ（読み取りのみ）。マイドライブ・共有アイテム・共有ドライブ・スター付き
- 開く・共有（端末へ取得。Google ドキュメントはリンクで）、フォルダをタブに割り当て
- 初回だけ Google Cloud での登録が要ります。設定 →「Google ドライブにつなぐ」に手順、パッケージ名と SHA-1 のコピー

## NAS（Synology）
- https の自己署名証明書：指紋を確かめて信頼できるように
- 2 段階認証に対応（初回だけコード、以後はデバイストークン）
- アドレスのポートを省略できる（:5000 を補う）。接続の結果をその場で表示

実機での確認はまだです。

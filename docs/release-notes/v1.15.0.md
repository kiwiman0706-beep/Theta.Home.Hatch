# Theta Home Hatch 1.15.0

- **ホームにもウィジェット・アプリ・ショートカットを置けます**
  - ホームの「すぐ記録」の下に「ホームに置く：＋ ウィジェットなど ＋ アプリ」が出ます
  - 「＋ ウィジェットなど」：ウィジェット・フォルダ・予定・通知・Hatch のアプリの棚など、タブに置けるものと同じ
  - 「＋ アプリ」：アプリと、そのショートカット（LINE のトークなど。「SC」から）
  - 置いたあとは右下の ⚙ で編集（高さ・半分の幅・並べ替え・外す・足す）。アプリは長押しのままドラッグで並べ替え
  - 区画の位置・出す画面は、設定 →「HOME / ホームの並び」の「ウィジェット・アプリ」で変えられます

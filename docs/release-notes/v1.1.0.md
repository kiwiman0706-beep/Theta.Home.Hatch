# Theta Home Hatch 1.1.0

- **ギガの残り**を画面上部に出せるようにしました（「GIGA 残り 6.2/13G」）
  - 設定 → GIGA で、今月の容量（GB）を入れると出ます
  - 端末が測った今月（1 日から）のモバイル通信量から出します。IIJmio の残量の API は 2025 年 1 月で終わったためです。使用状況へのアクセスの許可が要ります（タスクバーと同じ）
  - 繰り越し・チャージは「今月足した分」に入れるか、**My IIJmio の今の残量**を入れて合わせます。IIJmio の集計と少しずれるので、ときどき合わせてください
- 残りが決めた量（既定 1GB）を切ると「**MY IIJMIO 開く ›**」が出て、押すと My IIJmio が開きます（入っていなければ Google Play）
- GIGA を押すと、容量・残量を合わせる画面が開きます

実機での確認はまだです。

# Theta Home Hatch 0.24.0-alpha

## タブに印（アイコン）
- 端のタブの名前の上に、パッと見て分かる印が付きます。中身から自動で、フォルダ・予定・メール・LINE・人・栞・Clip・記録・Hatch・Web・ファイルは記号、アプリのカテゴリーはいちばん前のアプリのアイコンです
- タブを長押し →「印（アイコン）を変える」で、記号（26 種）・アプリのアイコン・出さない・自動に戻す、を選べます
- ドロワーの見出しにも同じ印が出ます

## テーマを 2 つ追加（設定 → THEME）
- **ALERT（警報画面）**：黒地に橙の文字、警告の赤と正常の緑。見出しの上に太い警告の帯、背景に走査線
- **SCI-FI（操作卓）**：黒に近い青緑の地に方眼、黄・水色・緑の 3 色

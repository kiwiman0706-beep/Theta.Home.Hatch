# Theta Home Hatch 0.9.0-alpha

## 検索フォルダ（仮想フォルダ）
条件を保存して、合うファイルをフォルダのように一覧で出します。Google ドライブと NAS の両方。

- 条件：種類（写真・動画・音楽・PDF・文書・表・スライド）、ファイル名に含む言葉、更新した時期（今日・7 日・30 日・1 年）、場所
- Google ドライブはさらに、本文に含む言葉（PDF や文書の中身）、スター付き、共有されたもの
- ドライブ・NAS の入口に並びます。入口の「＋ 検索フォルダを作る」か、フォルダを長押し →「この中の検索フォルダを作る」
- 長押しで「条件を変える・消す」「〇〇のタブにする」
- ドライブには初めから RECENT 7D・PDF・PHOTOS・OFFICE を用意（消せます）
- 結果は新しい順。見せ方は検索フォルダごとにも覚えます。設定の書き出しにも含めます

NAS の場所を「どこでも」にすると共有フォルダ全部を探すので、少し時間がかかります（最大 30 秒で打ち切り）。
実機での確認はまだです。

# Theta Home Hatch 0.38.0-alpha

- **GOOGLE DOCS（検索フォルダ）**：Google ドライブの入口に、**Google ドキュメント・スプレッドシート・スライド**を**自分が最近開いた順**に並べるフォルダを初めから置きました
  - ホームのファイラーで DRIVE を開くと、RECENT 7D・PDF・PHOTOS・OFFICE と並んで出ます
  - 押すと Google のドキュメントなどのアプリ（無ければブラウザ）で開きます
- **DOCS のタブ**：上のフォルダを開くタブを、初めから端に置きました（WORK・PRIVATE・PHOTO の後ろ）
  - 前から使っている人にも、一度だけ足します。いらなければタブの長押し →「このタブを外す」。外したら戻しません
  - Google ドライブにつないでいないときは、タブの中に「つなぐ」の案内が出ます（設定 → NAS・GOOGLE DRIVE）
- 検索フォルダを作る・直す画面に、**並び**（更新した順・自分が最近開いた順）と、種類「**Google 文書・表・スライド**」を足しました（ドライブだけ）

実機での確認はまだです（ドライブにつないだ状態での並びは、この環境では確かめられていません）。

# Theta Home Hatch 0.14.0-alpha

## レスキュー（もしものときの逃げ道）
ベータ版のホームが更新で固まる・落ちるようになっても、抜け出せるようにしました。

- **クイック設定のタイル「ホームのレスキュー」**：通知パネルから開けます。本体とは別のプロセスで動くので、ホームが固まっていても反応します
  - 設定 → RESCUE の「クイック設定にタイルを足す」（Android 13 以降）か、通知パネルの編集から足してください
- **自動でレスキュー画面**：起動してすぐ落ちる・止まる・8 秒以上固まる、が 5 分に 3 回続いたら、次の起動ではホームの代わりにレスキュー画面を出します
- **レスキュー画面**：別のホームアプリを選ぶ／セーフモードで開く（ウィジェットと天気を止める）／普通に開き直す／最新版を入れる／Android の設定／不具合を伝える
- 設定に「RESCUE / もしものとき」：別のホームアプリを選ぶ・レスキュー画面を開く・タイルを足す

最後の手段：通知パネルの歯車 → アプリ → 標準のアプリ → ホームアプリ。
実機での確認はまだです。

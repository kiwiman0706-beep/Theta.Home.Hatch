# Theta Home Hatch 0.23.0-alpha

## エッジをホームと同じタブ・中身に
ほかのアプリを使っているときに画面の端から引き出すタブ（設定 → EDGE）が、ホームと同じになりました。
- ウィジェット・フォルダ・予定・メールなどの通知・Web ページ・画像や PDF・置いたアプリやショートカットも、そのまま出ます
- 下のアプリが透けて見える画面を重ねます。タブはエッジの側（左右）に、最後に開いていたタブを開いた状態で出ます
- 外側を押すか「戻る」で閉じます。アプリを開くと自動で閉じます
- ホームとエッジは同じものを使うので、エッジで足したもの・変えたものはホームにもそのまま反映されます

実機での確認はまだです。

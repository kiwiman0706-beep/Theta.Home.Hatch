# Theta Home Hatch 1.0.0

Theta Hatch シリーズに入りました。**ID と鍵が変わったので、0.42 までとは別のアプリとして入ります。**

## はじめにすること

1. この APK を入れる（「提供元不明のアプリ」の許可）
2. 古い Home（0.42 まで）の 設定 → 書き出し で保存し、新しい Home の 設定 → 読み込み で戻す
3. 設定 →「既定のホームにする」で新しい Home を選ぶ
4. 許可を入れ直す：通知へのアクセス（LINE・メール・音楽）、使用状況へのアクセス（タスクバー）、ほかのアプリの上に表示（エッジ）、すべてのファイルへのアクセス（Download）、カレンダー・連絡先
5. ウィジェットを置き直す（ウィジェットの割り当ては持ち越せません）。Dimple などに置いた「タブを出す」ショートカットも置き直す
6. Google ドライブにつなぎ直す（新しい ID はシリーズの Google Cloud に登録済み）
7. Hatch の一覧の「移行が必要」で、古い Home の「古いアプリを削除」

## 新しいこと

- **更新のハブ**：Hatch の一覧で、シリーズの Android アプリを「更新」「すべて更新」「入れる」。取得したら SHA-256・署名（シリーズ共通の鍵）・パッケージ・版を確かめてから入れます。このホームが入れたアプリは、次から確認なしで更新できることがあります
  - 12 時間に 1 回、裏で確かめます（設定 → UPDATE「自動で更新する」既定オン、「モバイル回線でも取得する」既定オフ）
  - KidsHome が既定のホームアプリのときは、裏の更新は KidsHome に任せます
- **移行**：古い ID のアプリがあると、一覧の上に「移行が必要」と段階ごとのボタン
- **設定のハブ**：スキン・Gemini・NAS・Google アカウントを、シリーズのアプリに渡します。API キー・パスワードは相手のアプリで選んだときだけ貸し、通知で知らせます（設定 → SERIES）
- MemoHatch・DSBooks・Theta Music は、新しい ID と古い ID のどちらでも連携します
- 自動化アプリから呼ぶアクションは `app.thetahatch.home.SHOW_TABS`・`QUICK`・`VOICE_APP` に変わりました

実機での確認はまだです（特に、確認なしの更新・移行の書き出しと読み込み・裏の更新）。

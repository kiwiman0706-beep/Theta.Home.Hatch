# Theta Home Hatch 1.9.0

- **Hatch のアプリのタブ**
  - 端の「＋」→「＋ MemoHatch」のように、シリーズのアプリごとのタブを作れます（ふつうのタブの「＋ 足す」にも置けます）
  - そのアプリが Home に見せるもの（MemoHatch のピン留めメモ、Music のお気に入りなど）と、「開く」ボタンが出ます
  - 中身を出すには、各アプリの対応が要ります（今は「開く」だけ）。Series に頼んでいます
- **音楽が流れていないとき**は、Theta Music のお気に入り・最近のアルバムをジャケットで横に並べ、押すと再生します（Theta Music の対応待ち。対応するまでは今まで通り）
- **メールのタブで、Gmail の「重要」だけを出せます**
  - タブの上の「通知」「Gmail」で切り替えます。Gmail は「重要」が既定で、⚙ で「重要・未読」「スター」「未読」や、Gmail の検索の書き方（label:仕事 など）に変えられます
  - 初めて使うとき、Google の許可の画面が出ます
  - **準備**：Google Cloud のシリーズのプロジェクトで「Gmail API」を有効にしてください（API とサービス → ライブラリ → Gmail API → 有効にする）。有効でないと「Gmail API を有効にしてください」と出ます

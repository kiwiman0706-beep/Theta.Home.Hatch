# Theta Home Hatch 1.3.0

- **すぐ記録が 4 つ**になりました：撮る・録る・描く（手書き）・打つ（文字）
- **録るは文字起こし付き**：録音を止めると Gemini で文字起こしして、入力の画面に文字を入れて開きます。そこから LINE・メール・AI・コピー・メモへ送れます
  - 録音と文字は「記録」に残ります。Gemini のキー（設定 → アイコンの Gemini と同じもの）が無いときは録音だけ残します
  - 18 分くらいまでの録音が対象です
- **入力の送り先**を増やしました
  - **コピー**（クリップボード）
  - **AI に聞く**：Gemini・Claude・ChatGPT（入っているアプリだけ出ます）
  - 「送り先…」で、いつもの送り先の並びにも入れられます
- 入力の画面に「**話して入れる**」の大きなボタンを置きました

実機での確認はまだです。

# Theta Home Hatch 0.21.0-alpha

## ふつうのタブ（BOARD）
1 つのタブに、ウィジェット・フォルダ・画像や PDF・Web ページを好きな数だけ並べられます。
- 「＋」→ BOARD の「ウィジェットから」または「空のタブ」
- 見出しの歯車で編集：「＋ 足す」、下の帯をなぞって高さ、全幅／半分（半分どうしは横に並ぶ）、▲▼で並べ替え、外す
- フォルダは端末のフォルダを選ぶか、フォルダのタブと同じ場所（NAS・Google ドライブも）。中で辿れます
- 並びは両方の画面で共通、高さは画面（閉じた／開いた）ごと。ドロワーの幅は内側の端の取っ手で

## ウィジェットのタブは BOARD に
今までのウィジェットのタブは、更新すると BOARD に移ります。ウィジェットの高さ・ドロワーの幅・タブの設定・置いたショートカットはそのまま引き継ぎます。
ウィジェットの横幅は、ドロワーの幅（全幅）かその半分になります。

# Theta Home Hatch 0.33.0-alpha

- **通知を条件で絞ってホームに出す**：条件に合う通知だけを、ホームの予定と天気のあいだ（Fold5 を開いたときは時計の下）に出します
  - 条件は「アプリ」「含む言葉（どれか 1 つ）」「除く言葉」で決めます。例：LINE の家族だけ、「至急」を含むメールだけ、「配達」を含む通知だけ、「広告」は除く
  - 合うものが無いときは区画ごと出しません。見出しを押すとたためます（たたむと件数と最新の 1 件）
  - 「目立たせる」にした条件に合った通知は、左にアクセントの帯
  - 押すと開く、右へスワイプで既読、長押しで返信など（タブの中の通知と同じ）
  - 条件の作り方：設定の NOTICE FILTER、区画の「FILTER ⚙」、通知の長押し「このアプリの通知をホームに出す…」
  - 言葉はひらがな・カタカナ・全角半角・大文字小文字の違いを見ません
- ダッシュボードで区画が増えたり減ったりしたとき、区画が重なって出ることがあったのを直しました

通知の内容は端末の中だけで使い、保存も送信もしません。実機での確認はまだです。

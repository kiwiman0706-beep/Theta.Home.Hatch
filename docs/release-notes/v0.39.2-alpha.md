# Theta Home Hatch 0.39.2-alpha

- **Dimple などから「タブを出す」で開くと、少し遅れてホームが出てしまう**ことへの対策です
  - ショートカット・アプリの一覧の入口から開くときは、まず何も描かない中継を開き、すぐ消えるようにしました
  - エッジ（設定 → EDGE）がオンなら、端の取っ手を押したときと同じく常駐の側から開きます（取っ手からは下のアプリの上に出るので、それと同じ開き方にしました）
  - 「すぐメモ」「声で入力」「文字で入力」「写真で入力」「声でアプリ」も同じ中継を通ります
- Dimple の割り当ては、ショートカットの「タブを出す」・アプリの一覧の「タブを出す」のどちらでも同じです（更新後、Dimple 側で選び直しが要るかもしれません）

実機での確認はまだです。まだホームが出るときは、エッジがオンかオフかと合わせて教えてください。

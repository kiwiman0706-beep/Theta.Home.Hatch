# Theta Home Hatch 0.29.0-alpha

## ピン留め（よく使うアプリ・ショートカット）
- よく使うアプリ・ショートカットを 8 つまで、端のタブの下（START の上）に小さく並べられます。タブをスクロールしても隠れません
- すべてのアプリ（START）を開いたときも、いちばん上に「PINNED」として同じものが並びます
- 置き方：アプリ・ショートカットを長押し →「ピン留め」。または「＋」→ PINNED でまとめて選ぶ（「SC」でショートカットも）。ほかのアプリの「ホーム画面に追加」でも「ピン留め」を選べます
- 端の下の印を長押しすると、上へ・下へ・ピン留めを外す
- 何もピン留めしていなければ、何も出しません

実機での確認はまだです。

# Theta Home Hatch 0.19.0-alpha

## エッジ：ほかのアプリの上で、画面の端からタブ
設定 → EDGE をオンに。
- どのアプリを使っていても、画面の端の細い線を内側へなぞる（または押す）と、カテゴリーのタブとアプリが出ます
- 端の側にタブの列（＋ALL）、内側にアプリとショートカット。並びはホームと同じで、通知の件数も付きます
- HOME でホーム全体へ。外側を押すか「戻る」で閉じます。ホームを開いている間は線を隠します
- 左右の端と高さ（5 段）を選べます。初めは左（右は Galaxy のエッジパネルと重なりやすいため）
- 「ほかのアプリの上に表示」の許可が要ります。消されないよう常駐の通知が出ます（通知の「止める」でも切れます）

実機での確認はまだです。

# Theta Home Hatch 0.36.1-alpha

- **ホームの検索の箱から Google 検索・声で検索**
  - 箱は今までと同じで、打つとホームの中（アプリ・タブ・ファイル・人・栞など）を探します
  - 箱の中の**マイク**：声で箱に入れる（そのままホームの中を探す）。**長押しで Google の音声検索**
  - 箱の中の**地球**：箱の言葉で **Google 検索**（空なら Google の検索画面）。キーボードの「検索」キーでも同じ
  - Google アプリが無ければ、ブラウザで google.com を開きます
- **1 文字打つとキーボードが閉じていたのを直しました**（打ち始めにホームの並びが切り替わり、箱が作り直されていたため。並びを変えずに、箱の下に結果を出すようにしました）

実機での確認はまだです。

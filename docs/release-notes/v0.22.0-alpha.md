# Theta Home Hatch 0.22.0-alpha

## タブは「ふつうのタブ」と「アプリのカテゴリーのタブ」の 2 つだけに
- 予定・メール・LINE・人・栞・Clip・記録・Hatch も、ふつうのタブに置ける中身になりました。フォルダ・Web ページ・画像や PDF・ウィジェットと一緒に、1 つのタブに好きな数だけ並べられます（見出しの歯車 →「＋ 足す」）
- 置いたものは「縦いっぱい」（残りの高さを分け合う）か、高さを決めるかを選べます。幅は全幅か半分
- 「＋」でタブを作るときは、中身を 1 つ入れて作ります（ウィジェット・フォルダ・Web ページ・画像や PDF・予定など）。「空のタブ」も

## 今までのタブは自動で移ります
0.21.0 までのフォルダ・予定・メールなどのタブは、中身が 1 つ（縦いっぱい）のふつうのタブになります。見た目・名前・フォルダの場所・置いたアプリとショートカットはそのままです。
Alt＋1〜9（フォルダ）・Alt＋C（予定）などのキーも、そのまま使えます。

実機での確認はまだです。

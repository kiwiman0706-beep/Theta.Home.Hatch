# Theta Home Hatch 1.17.0

- **Google の文書・表・スライドのタブ**：端の「＋」→「＋ Google 文書・表・スライド」。Google ドライブのドキュメント・スプレッドシート・スライドだけを、最近開いた順に並べます
- **フォルダのタブにウィジェットを足しても、全部見られます**：ウィジェットなどと一緒に置いたときは、タブ全体がスクロールします。フォルダは画面の高さぶんになり、その中でもスクロールできます
- **すぐ記録のカメラ**は Theta Camera Hatch を開きます（入っていなければ MemoHatch の写真のメモ）。文字・チェックリスト・手書き・声は、MemoHatch の入力の段と同じ動きです
- **MemoHatch のタブ**のいちばん上に、新しいメモのボタン（文字・チェックリスト・手書き・声・カメラ）を置きました

# Theta Home Hatch 0.27.0-alpha

## Word・Excel・PowerPoint を中でプレビュー
ファイルを押すと、docx・xlsx・pptx もホームの上のポップアップで中身を見られます。
- **Excel**：シートを切り替えて表で。日付の書式のセルは日付として出します
- **Word**：見出し・本文・箇条書き・表・画像を、白い紙の上に
- **PowerPoint**：スライドごとに、題・箇条書き・画像

中の文字・表・画像だけを取り出すかんたんなプレビューなので、見た目どおりではありません。正確に見たいときは上の「アプリで開く」から。古い形式（doc・xls・ppt）やパスワード付きのファイルは、今までどおりほかのアプリで開きます。

実機での確認はまだです。

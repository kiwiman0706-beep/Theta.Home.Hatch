# Theta Home Hatch 0.16.0-alpha

## アイコンを 3 色に
- 地・基本・アクセントの 3 色に塗ります。配色は設定 → ICON で選べます：HUD（白＋オレンジ）・オレンジ・塗り（オレンジ地）・モノクロ・自分で選ぶ（3 色を 1 つずつ）
- 型は色に依らないので、配色やテーマを変えても作り直しません
- 簡易加工：形の中で 2 番目に多い色をアクセントにします
- Gemini：白・黒・赤の 3 色で描き直してもらいます。前の 2 色の型もそのまま使え、「2 色のものを 3 色で作り直す」もできます（1 アプリ 1 回の課金）

## 声でアプリを開く
- START（または検索の横のアプリのボタン）でアプリの一覧を開くと同時に聞き取り、「LINE」「カメラ開いて」のように言うとそのアプリを開きます。決まらないときは聞き取った言葉で絞り込み
- 設定 → VOICE で「使わない・押したとき・長押ししたとき」（初めは長押ししたとき）
- 一覧の中のマイクのボタンからも

## カレンダー（月）
- 日をまたぐ予定は、始まりの日と週の頭（日曜）にだけ名前を出し、ほかの日は色の帯で続けます

# Theta Home Hatch 0.20.0-alpha

## フォルダのタブはドロワーで
- フォルダのタブを押すと、ドロワーの中にフォルダの中身が出ます（背景は切り替わりません）
- 場所はタブごとに覚えます（NAS・Google ドライブのフォルダも）。戻るで上のフォルダへ
- 開いた画面の背景は、左の「場所」で「最近」か決めたフォルダを切り替えます

## タブは両方の画面で共通に
- 閉じた画面と開いた画面でタブは同じ。0.19.0 までの画面ごとのウィジェットのタブは 1 つにまとめます（大きさはそれぞれの画面のものを残します）
- ドロワーの幅は画面ごとに覚えます：内側の端の取っ手をなぞる、2 回押すと元の幅
- タブを長押し →「閉じた画面だけに出す／開いた画面だけに出す」。隠したタブは「＋」から戻せます

## 新しいタブ
- **WEB**：決めた URL のページをタブの中に。リンクもタブの中で開き、戻るでページを戻ります
- **FILE**：決めた画像・PDF をタブの中に。画像は指で拡大（2 回押すと元）、PDF はページを縦に並べます

## アプリ・ショートカットをどのタブにも
- タブを長押し →「アプリ・ショートカットを置く」。ドロワーの上に並びます
- ほかのアプリの「ホーム画面に追加」（LINE のトークルームなど）も、置くタブを選べます
- カテゴリーのタブは、長押し →「ショートカットを別の段に」で、アプリと分けて並べられます

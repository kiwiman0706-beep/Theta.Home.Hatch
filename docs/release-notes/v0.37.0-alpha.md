# Theta Home Hatch 0.37.0-alpha

- **タスクバー（閉じた画面の下）**
  - 左に**最近使ったアプリ**（下にオレンジの印）、区切りのあとに**よく使うアプリ**。画面に入るだけ並べます
  - 押すと開きます。長押しで名前
  - **タブを出しているときも見えます**（ホームの一番下に固定）
  - **使用状況へのアクセス**を許可すると、通知やほかのアプリから開いたものも含めた端末の記録から出します（設定 → TASKBAR の「使用状況へのアクセスを許可」）。許可しなければ、このホームから開いた記録から出します
  - 設定 → TASKBAR で、閉じた画面・開いた画面に出すかを選べます（開いた画面は Galaxy のタスクバーがあるので、初めは出していません）
  - エッジ（ほかのアプリの上に出したタブ）では出しません

実機での確認はまだです。

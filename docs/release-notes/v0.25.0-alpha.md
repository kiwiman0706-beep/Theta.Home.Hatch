# Theta Home Hatch 0.25.0-alpha

## 天気の欄に警報・注意報
- 天気の場所（市区町村）に出ている、気象庁の警報・注意報を並べます
- 特別警報は紫、警報は赤（塗り）、注意報は黄（枠）。強いものから並べ、押すと気象庁の警報・注意報のページを開きます
- 何も出ていなければ「警報・注意報なし」と小さく出ます。天気と一緒に取り、10 分ごとに取り直します
- 場所は国土地理院の逆ジオコーダで市区町村を決め、気象庁の地域に当てはめます（政令市は市でまとめて）。日本の外では出しません

実機での確認はまだです（開発の環境から気象庁・国土地理院につなげなかったため、読み取りは気象庁の形に合わせたテストで確かめています）。

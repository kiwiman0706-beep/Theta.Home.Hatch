# Theta Home Hatch 0.41.0-alpha

- **再生中の音楽をホームとタブに**
  - ホームの区画「**音楽**」（予定・ピン留めの下）と、タブに置ける「**MUSIC**」（端の「＋」→「＋ MUSIC」、ふつうのタブの「＋ 足す」→「＋ MUSIC」）
  - **ジャケット・曲名・アーティスト・アルバム・進み具合**を出し、**前の曲・再生／一時停止・次の曲**、「**開く**」（ジャケットを押しても）でアプリへ
  - どの音楽アプリでも動きます（Android のメディアセッションを読む）。**Theta Music を先に**、なければ再生中のもの、なければ最後に使ったもの
  - **通知へのアクセス**が要ります（LINE・メールと同じ許可）。区画の中に案内とボタンが出ます
  - 再生していなくて Theta Music も入っていなければ、区画は出しません。見出しを押すとたたみ、たたむと「▶ 曲名 — アーティスト」の 1 行
- 直したこと
  - タスクバーの「最近」が、ホームに戻ったときに読み直されていなかった（最大 5 分遅れていた）
  - 回線の速さの 5 分おきの計り直しが始まっていなかった（ホームに戻ったときと回線が変わったときだけ測っていた）

実機での確認はまだです。

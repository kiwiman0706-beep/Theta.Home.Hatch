# Theta Home Hatch 1.10.0

- **アプリの読みを Gemini で自動で付けます**
  - 英語の名前のアプリ（Gemini・Slack など）に、声で呼ぶときの読み方（じぇみに・すらっく など）や、よくある略し方（ようつべ など）を付けます。声で開く・検索のときに使います
  - 設定 → 「VOICE / アプリの読み」で「読みの無いアプリに付ける」を一度押してください（全アプリに付けます）。「全部付け直す」もあります
  - Gemini に送るのはアプリの名前とパッケージ名だけです
  - 付いた読みは、アプリを長押し →「呼び名」の画面で見られます。自分で付けた呼び名もそのまま使えます
- **毎日自動で**
  - Wi-Fi で充電中に 1 日 1 回、新しく入れたアプリに読みを付け、アイコンを Gemini で加工します（アイコンは、Gemini のアイコンを使っているとき）
  - アプリを入れたときも、その分だけすぐ作ります
  - 設定の「新しいアプリに読みを自動で付ける」「新しいアプリのアイコンを自動で加工する」で止められます（既定はオン）

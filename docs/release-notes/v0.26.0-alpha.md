# Theta Home Hatch 0.26.0-alpha

## ファイルを中で開く
ファイルを押したとき、対応している形式は、ほかのアプリに切り替えずにホームの上のポップアップで開きます。
- **画像**（JPEG・PNG・HEIC・AVIF・動く GIF/WebP など）：2 本指で拡大、2 回押すと拡大・元に戻す
- **動画・音声**（mp4・mkv・webm・mp3・m4a・flac・ogg・wav など）：ExoPlayer で再生
- **PDF**：ページを縦に並べて
- **文字**（txt・md・json・ログ・ソースコードなど）：選んでコピーできます。JSON は整えて、Shift_JIS の日本語のファイルも読めます
- **CSV・TSV** は表で、**zip** は中身の一覧で（Windows で作った日本語の名前も）

左右にめくると、同じフォルダのほかのファイルへ。上の「共有」「アプリで開く」で、今までどおりほかのアプリへ渡せます。NAS・Google ドライブのファイルも、取得してから同じように開きます。ほかの形式は今までどおりほかのアプリで開きます。
設定 → VIEWER でオフにもできます。

次の版で、Word・Excel・PowerPoint（docx・xlsx・pptx）のかんたんなプレビューを足す予定です。

# Theta Home Hatch 1.7.0

- **人と LINE のトークを結ぶ**
  - PEOPLE で人を押して「LINE と結ぶ」→ LINE のトークを選びます（名前の近いものが上に出ます）
  - 結ぶと「LINE（トークの名前）」のボタンで、そのトークが直接開きます
  - 選べるのは、Home から見える LINE のトーク（最近やりとりしたもの・LINE で「ホーム画面に追加」したもの）です。LINE は友だちの一覧を外に出さないためです
  - 結んだトークは固定しておくので、最近の一覧から消えても開けます
- **よく連絡する人**
  - ホームの区画（「よく連絡する人」）と PEOPLE の上に、顔を横に並べます。「＋」で連絡先か LINE のトーク（グループなど）から足します
  - 押すと、LINE と結んでいれば LINE、無ければ電話。長押しで LINE・電話・SMS・メール・前へ・後ろへ・外す
  - LINE の未読の数を、顔の右上に出します（通知へのアクセスが要ります）
- 設定の書き出し・読み込みにも入ります

LINE のトークが長く同じ ID のままか、未読が正しく数えられるかは、実機で確かめます。

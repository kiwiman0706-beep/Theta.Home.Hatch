# Theta Home Hatch 0.16.1-alpha

## 通知をスワイプで
タブの中の通知（MAIL・LINE・カテゴリーのタブ）で使えます。

- **右へスワイプ＝既読**：通知に「既読」のボタンがあるアプリ（LINE など）はそれを押します（相手にも既読が付きます）。無いアプリは通知を消します
- **左へスワイプ＝設定で選ぶ**：返信（初め）・1 時間後にまた・消す・アプリで開く（設定 → NOTICE）
- **返信**はその場で入力して送ります（通知の「返信」と同じ）。返信できない通知はアプリを開きます
- **長押し**で、その通知のボタン（アーカイブ・ミュートなど）も選べます

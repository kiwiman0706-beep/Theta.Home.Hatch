# Theta Home Hatch 1.5.0

- **貼り付けて登録（Gemini）**
  - PEOPLE のタブと予定（カレンダー）のタブに「＋ 貼り付けて登録」を置きました
  - メールの署名・本文などの文章を貼る、話す、スクショや写真を選ぶ → 「読み取る」で、Gemini が連絡先・予定を読み取ります
  - 読み取った中身を直してから「連絡先に追加」「予定に追加」で、端末の追加画面が開きます（保存はそこで。このアプリは書き込みません）
  - 予定は「来週火曜 10 時」なども日付にします。複数の人・複数の予定もまとめて読めます
  - Gemini のキーは、設定のアイコンの Gemini と同じものを使います
- **Meishi・Chirashi の「撮って登録」**の入口を用意しました。それぞれのアプリが対応したら、PEOPLE に「名刺を撮る（Meishi）」、予定に「チラシを撮る（Chirashi）」が自動で出ます

実機での確認はまだです。

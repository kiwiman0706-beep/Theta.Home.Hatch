# Theta Home Hatch 0.13.0-alpha

## ウィジェット
- 1 つのタブに、ウィジェットを何個でも縦に並べられるように
- ふだんはウィジェットだけ。見出しの歯車で編集：角をなぞって大きさ・▲▼・外す・「＋ ウィジェットを足す」・もう一方の画面から取り込む
- パネルは中身の高さだけの小さなもの（ピン留めしたときは縦いっぱい）

## ドロワーの見出し
- 1 行に（[種類]·番号・名前・ボタン）。大きな見出しと、ウィジェットの下のボタンの列をなくしました（名前・並べ替え・外すはタブの長押し）

## アプリのショートカット
- カテゴリーのタブに、アプリのショートカットを置けるように（LINE のトークルームなど）
  - アプリを長押し →「ショートカット（タブに置く）」→「置く」
  - 各アプリの「ホーム画面に追加」からも。置くカテゴリーを選べます（初めはそのアプリのカテゴリー）
- アイコンの角にオレンジの印。長押し→ドラッグで並べ替え、動かさずに離すと「名前を変える」「外す」
- このアプリが既定のホームのときだけ使えます（Android の決まり）

実機での確認はまだです。

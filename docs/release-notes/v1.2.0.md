# Theta Home Hatch 1.2.0

ホームのメリハリを付け直しました。よく使うものを大きく、ふだん見ないものを小さくしています。

- **すぐ記録**：検索の下に「撮る・録る・書く」の大きいボタン
  - 撮る・書くは「入力」と同じ（MemoHatch に残してから送り先を選ぶ）。録るは録音で、もう一度押すと止まります
- **天気**はふだん 1 行（今の天気と 3 日分）。24 時間・7 日の予報は「詳しく ▾」で開きます
- **音楽**は止まっているとき 1 行になります
- **つながり**（NET・SPEED・TAILSCALE・NAS）は、全部が正常なら小さな 1 行。問題があるときだけ今までのチップが出ます。「依頼」のボタンは設定に移しました
- **開いた画面が 2 列になりやすく**しました（両側のタブでも）。右の列に何も置いていなければ、ファイラーを右に出します
- 端末（電池・容量）と、閉じた画面の「ファイルへの入口」は出さないようにしました（設定 →「HOME / ホームの並び」で戻せます）
- 強調色（黄色・オレンジ）は、もうすぐの予定と押すボタンに絞りました。フォルダは塗りつぶしをやめました
- **SOFT・BRAUN・WINDOW・POP の余白を詰めました**（枠の内側・区画の間・影・角丸・見出しの帯）
- 時計の下の目盛りと、「MON / 月曜日」の重複を外しました

実機での確認はまだです。

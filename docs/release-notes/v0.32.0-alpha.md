# Theta Home Hatch 0.32.0-alpha

- **予定を 3 日分など**：ホームの予定を、今日から 1・3・7 日分出せます（初めは 3 日）
  - 予定の見出しの「3D」を押すたびに 1 → 3 → 7 日と切り替わります
  - 日ごとに「今日 10/28 水」「明日 10/29 木」のような見出しが付きます（予定の無い日は出しません）
- **区画をたためます**：ダッシュボードの TODAY・WEATHER・FILES・DEVICE は、見出しを押すとたたみます（もう一度押すと広げる。たたんだのは覚えておきます）
  - たたんだ予定は、次の予定を 1 行だけ
  - たたんだ天気は、気温・天気と、警報・注意報があればその名前を 1 行で
  - 広い画面（Fold5 を開いたとき）のファイラーの上の予定も、見出しの ▾ でたためます

実機での確認はまだです。

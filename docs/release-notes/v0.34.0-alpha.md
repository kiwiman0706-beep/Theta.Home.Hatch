# Theta Home Hatch 0.34.0-alpha

- **マンガ（CBZ）をホームの中で読めます**：1 ページずつめくります
  - 右上の「右開き／左開き」で向きを切り替え（初めは右開き。覚えておきます）
  - 2 回押すと拡大、拡大中は 1 本指で動かせます。下にページ数
  - ページは名前順（「2」は「10」より前）。画像以外のファイルは飛ばします
- **PDF を 1 枚ずつ**：中で開いた PDF の右上の「続けて／1枚ずつ」で切り替え。1 枚ずつのときは右開き・左開きも選べます
- **DSBooks と連携**
  - EPUB・CBR・M4B を押すと、DSBooks が入っていれば DSBooks で開きます（DSBooks が取り込んでから、その本を開く。同じ本は二重に登録されません）
  - PDF・CBZ は、ビューアの上の「DSBooks」から DSBooks に渡せます
  - **DSBooks 0.8.7 以降が必要です**（ほかのアプリから開けるようにした版）。DSBooks のリポジトリのブランチ `ccr-fbd7a73d-mp81q5` にあります。署名はいつもの鍵でビルドしてください
  - 古い DSBooks のままなら、今までどおりほかのアプリで開きます

実機での確認はまだです。

# Theta Home Hatch 0.39.0-alpha

- **よく使うファイルをピン留め**できます
  - ファイルを**長押し →「ピン留め（ホームにいつも出す）」**。端末のフォルダ・NAS・Google ドライブのどれでも、ホームのファイラーでもタブの中のフォルダでも同じです
  - ホームに区画「**ピン留めのファイル**」が出ます（留めたものがあるときだけ）。押すと開きます（NAS は取得してから、Google のドキュメントなどは Google のアプリで）。8 件より多いときは「ほか ○ 件」からファイラーへ
  - ファイラーの場所に「**ピン留め**」を足しました。ここでは長押しで上へ・下へ・外す
  - 外すときは、区画の行を長押し、またはファイルの長押し →「ピン留めを外す」
  - ホームの並び（設定 → HOME）で、区画の位置・出す画面を変えられます。設定の書き出し・読み込みにも入ります
- 後から足したホームの区画（今回の「ピン留めのファイル」など）は、最後ではなく初めの並びの位置（通知の下）に入るようにしました

実機での確認はまだです。

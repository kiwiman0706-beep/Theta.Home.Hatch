背景にファイラーを置き、画面の端のタブでドロワーやウィジェットを切り替える Android のホームアプリ。**実機での確認はまだの試験版です。**

## 入れ方

下の **ThetaHomeHatch-0.7.0-alpha.apk** をスマホで開いてインストール。0.2.0 以降を入れていれば上書きできます（同じ鍵で署名）。**この版からは、アプリの中から次の版に更新できます。**

- package `jp.yaegaki.theta.home`／Android 10 以上
- 署名証明書 SHA-256 `c2b829ead59b1cc57fc29d5bedf979c2c9549277ba8fcbb711b7a7b7654dfae2`

## 0.7.0-alpha の変更

- **ホームアプリとして登録**：既定のホームになっていなければ、画面上部に「HOME 未設定」。押すと Android の選択画面へ。設定の先頭にも
- **自動更新**：起動・復帰のとき（1 日 1 回まで）GitHub Releases を確かめ、新しい版があれば画面上部に「UPDATE」。押すと取得 → SHA-256 照合 → Android の確認画面。設定の「UPDATE」で今すぐ確認・オフにもできる
- **機能を頼む**：画面上部の「REQUEST 依頼 ↗」と設定から、開発の会話（Claude Code）を開く
- **アイコンのツートーン**：設定の「ICON」で、そのまま・モノクロ・ツートーン（簡易）・ツートーン（Gemini）。テーマの 2 色（形＝オレンジ、地＝面の色）で塗るので、ダーク・ライトどちらでも世界観がそろう。Gemini は自分の API キーで、未加工のアプリをまとめて加工（1 アプリ 1 回、アイコン画像を Google に送る）。未加工のアプリは簡易加工で表示
- **仕分けでアンインストール**：仕分けガイドとアプリの長押しメニューから、Android のアンインストール確認画面へ（システムアプリは無効化の案内）

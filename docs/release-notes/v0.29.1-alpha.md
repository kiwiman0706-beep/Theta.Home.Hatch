# Theta Home Hatch 0.29.1-alpha

- ピン留めの初めを **LINE・Google の音声検索・MemoHatch の音声メモ** にしました（入っているアプリのものだけ出ます。自分でピン留めを決めていたら、そちらのまま）
- アプリの中の操作もピン留めできます
  - **音声検索**：Google の音声検索をすぐ開く（Google アプリが無ければ端末の音声検索）
  - **音声メモ**：MemoHatch で新しい音声メモ（録音から）を開く
  - アイコンはそのアプリのアイコンに、右下のマイクの印
  - 「＋」→ PINNED の「＋ 音声検索」「＋ 音声メモ」で出し入れできます

実機での確認はまだです。

背景にファイラーを置き、画面の端のタブでドロワーやウィジェットを切り替える Android のホームアプリ。**実機での確認はまだの試験版です。**

## 入れ方

1. 下の **ThetaHomeHatch-0.5.0-alpha.apk** をスマホで開いてインストール（「提供元不明のアプリ」の許可が必要）
2. まず普通のアプリとして開いて動きを確かめ、設定 →「既定のホームにする」
3. 0.2.0〜0.4.0 を入れていれば上書きできます（同じ鍵で署名）

- package `jp.yaegaki.theta.home`／Android 10 以上
- 署名証明書 SHA-256 `c2b829ead59b1cc57fc29d5bedf979c2c9549277ba8fcbb711b7a7b7654dfae2`
- APK の SHA-256 は添付の `SHA256SUMS-0.5.0.txt`

## 0.5.0-alpha の変更

- アプリの仕分けガイド：カテゴリーを用意 → アプリを 1 つずつ出し、振り分け先を押していく（おすすめ表示、その場で新しいカテゴリー、戻す・あとで）
- アプリのドロワーをカテゴリーごとに表示、絞り込みと長押しでの変更、設定でカテゴリーの管理
- テーマ：ダーク・ライト・端末に合わせる

## これまでの主な機能

- 背景のファイラー（端末のフォルダ・Google ドライブ・NAS）、端のタブからスライドインするドロワー
- NAS（Synology）とネットワーク・Tailscale の状態表示、つながらないときの案内
- ウィジェットは 1 タブ 1 つ、大きさの変更、閉じた画面と開いた画面で別の設定
- 予定・連絡先・LINE とメール（通知から）・Clip・記録（録音・写真・手書き）・Hatch の入手と更新
- 見た目は計器盤（HUD）風

# Theta Home Hatch 0.31.0-alpha

- **思いついたらすぐ入力**：入力の画面（声・文字・写真で書いてから、LINE・メール・メモなど送り先を選ぶ）を、ほかのアプリからボタン 1 つで開けます
  - Dimple などでは、このアプリのショートカット「声で入力」「文字で入力」「写真で入力」を選びます
  - Galaxy のモードとルーチンの「アプリを開く」では、アプリの一覧の「すぐメモ」（声から）を選びます（設定で隠せます）
  - 今のアプリの上に透けて開き、送ったら・閉じたら元のアプリに戻ります。文字ならすぐキーボード、声ならすぐ聞き取りが始まります
  - 送るといつも MemoHatch に残ります（0.30.0 と同じ）
- **アプリの呼び名**：アプリを長押し →「呼び名をつける」。声でアプリを開くとき・検索で、その名前でも見つかります。いくつか付けるときは「、」で区切ります
- **声でアプリ**：すべてのアプリを開いて、すぐ聞き取ります。ピン留め（「＋」→ PINNED）や、ショートカット「声でアプリ」から

呼び名が効くのは、このホームの声でアプリを開くときです（Google の音声検索・Bixby には効きません）。実機での確認はまだです。

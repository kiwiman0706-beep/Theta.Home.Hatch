**背景（デスクトップ）にファイラーを置き、画面の端のタブでドロワーやウィジェットを切り替える** Android のホームアプリ。
スマホはアプリには行きやすいのにファイルには行きにくいので、PC のデスクトップのように「ファイルの置き場」をホームにする。ただ散らかして置くのではなく、ファイラーとして置く。

- 版：**0.39.0-alpha（versionCode 49）**／package `jp.yaegaki.theta.home`／Android 10（API 29）以上
- 対象：Galaxy Z Fold5（カバー・メイン）、Alldocube iPlay 60 / 80 Pro 系、Unihertz Titan 2（物理キーボード）
- **実機での確認はまだです。** 画面は JVM 上で描いて確かめています（[`docs/screenshots/`](docs/screenshots)）。

## ホームとタブ

- **ホーム**（タブではないところ）は区画の並び：時計・検索・予定・通知・天気・つながり・ファイルへの入口・**ファイラー**・端末。設定 →「HOME / ホームの並び」で、順番（▲▼）、**閉じた画面・開いた画面で出すか**（「閉」「開」）、**2 列のときの左右**を決める。開いた画面・タブレットでは 2 列（初めは左に時計・予定など、右にファイラー）。閉じた画面ではファイラーの代わりに「ファイルへの入口」。
- **タブ**はフォルダ・アプリ（ランチャー）・ウィジェットなどをポップアップで出すもの。フォルダのタブはタブ（ドロワー）の中で開く。ホームの「ファイルへの入口」のフォルダも、タブで開く。
- **タブの位置**：設定 →「見た目」で「開いた画面だけ両側」（初め）・「いつも片側」・「いつも両側」。両側のときは、カテゴリー（アプリ）のタブが START と反対側、ほかが START の側。タブの長押し「右側へ移す」「左側へ移す」で 1 つずつ変えられる。
- **検索の箱**：打つ・話すとホームの中（アプリ・タブ・ファイル・人・栞など）を探す。箱の中のマイクで声で入れる（長押しで Google の音声検索）、地球のボタンかキーボードの検索キーで Google 検索。
- **タスクバー**：閉じた画面の下に、最近使ったアプリ（下に印）とよく使うアプリを入るだけ並べる。タブを出しているときも見える。設定 → TASKBAR で、開いた画面にも出す・使用状況へのアクセスの許可（許可すると端末の記録から、無ければこのホームから開いた記録から）。
- **Google のドキュメントなど**：Google ドライブの検索フォルダ「GOOGLE DOCS」（ドキュメント・スプレッドシート・スライドを、自分が最近開いた順）と、それを開く「DOCS」のタブを初めから置く。検索フォルダは「更新した順／自分が最近開いた順」を選べる。
- **ファイルのピン留め**：ファイルを長押し →「ピン留め」（端末・NAS・ドライブのどれでも、タブの中のフォルダでも）。ホームの区画「ピン留めのファイル」とファイラーの場所「ピン留め」に並ぶ。区画の行を長押しで外す。
- **初めて入れたとき**：前の設定を読み込むか → 読み込まないならアプリを仕分けするかを聞く。
- **Hatch のアプリ**：設定のいちばん下「HATCH / Theta Hatch シリーズ」から、ほかの Hatch のアプリを入れる・更新する・開く。

## 狭い画面のダッシュボード・カレンダー

狭い画面（幅 600dp 未満：閉じた Fold5・Titan）の背景は、今日の予定・天気（Open-Meteo）と気象庁の警報・注意報・つながり・ファイル・端末のダッシュボード。ファイラーは「FILES」の場所を押すと開く（フォルダのタブはドロワーで開く）。カレンダーのドロワーは月（日曜始まり、予定は全部）・週・日。

## エッジ（ほかのアプリの上で端からタブ）

**「タブを出す」ショートカット**：端をなぞる代わりに、ほかのアプリから同じタブを出せる（エッジがオフでも使える）。Dimple などショートカットを置けるアプリでは「タブを出す」ショートカット、Galaxy のモードとルーチンでは「アプリを開く」でアプリの一覧の「タブを出す」を選ぶ。自動化アプリからはアクティビティのアクション `jp.yaegaki.theta.home.SHOW_TABS`。アプリの一覧の「タブを出す」は設定 → SHORTCUT で隠せる。

設定 → EDGE をオンにすると、どのアプリを使っていても、画面の端の細い線を内側へなぞる（または押す）だけで、**ホームと同じタブと中身**（ウィジェット・フォルダ・予定・アプリ・置いたショートカットなど）を下のアプリの上に重ねて出せます。外側を押すか「戻る」で閉じ、アプリを開くと自動で閉じます。左右の端と高さを選べます。「ほかのアプリの上に表示」の許可と、常駐の通知が要ります。ホームキーの動き（押すとホーム全体）は Android の決まりなので変えていません。

## 見た目

計器盤（HUD）風：黒地にオレンジ 1 色、細い線、四角い角。見出し・時計は Oswald、ラベル・数字は等幅の Share Tech Mono（同梱、SIL Open Font License、[docs/licenses](docs/licenses)）。日本語は端末の書体。テーマはダーク・ライト・**POP（カラフル）**・**ALERT（警報画面）**・**SCI-FI（操作卓）**・**TERMINAL**・**BRAUN**・**SOFT**・**WINDOW**・**LCD**・端末に合わせるから選べる（設定 → THEME）。POP はクリームの地にコーラル・イエロー・ミント、角丸と影、ゴシック体。ALERT は黒地に橙の文字と警告の赤・正常の緑、太い警告の帯と走査線。SCI-FI は黒に近い青緑の地に方眼、黄・水色・緑。

<img src="docs/screenshots/alert-main.png" width="320" alt="ALERT"> <img src="docs/screenshots/scifi-main.png" width="320" alt="SCI-FI"> <img src="docs/screenshots/alert-cover.png" width="160" alt="ALERT（閉じた画面）"> <img src="docs/screenshots/scifi-cover.png" width="160" alt="SCI-FI（閉じた画面）">

色だけでなく作りも変わるテーマ（0.36）：
- **TERMINAL**：緑の端末。黒地に蛍光の緑、見出しは反転した帯、文字は全部等幅、背景に流れる文字の列
- **BRAUN**：白い家電。めくり時計と丸い日付の文字盤、浮き出た角丸の台、オレンジ 1 色、丸いアイコン
- **SOFT**：やわらかい浮き出し。線を使わず影で台が浮く、大きな角丸、淡いオレンジ・青・緑
- **WINDOW**：昔のパソコンの窓。水色の地に白い方眼、区画はオレンジのタイトルバーに「_ □ ×」の窓、太い線と影
- **LCD**：液晶ゲーム機。くすんだ黄緑の地に濃い緑の太い線、全部等幅、液晶の数字の時計

アイコンを Gemini で描き直すときも、テーマに合わせて描き方を変える（計器盤のステンシル・ドット絵・丸くかわいい・細い線の家電ふう）。

## 画面の構成

- **背景＝ファイラー**（開いた画面）：上に時計・次の予定・検索、ネットワーク／Tailscale／NAS の状態。下は左の「場所」で、最近使ったファイルか、決めたフォルダ（タブに置いたフォルダ・NAS・ドライブ）を切り替えて出す。幅 860dp 以上では選んだファイルの中身（画像・文字）を右に出す。
- **端のタブ**は 2 種類だけ
  - **ふつうのタブ**：ウィジェット・フォルダ・画像や PDF・Web ページ・予定・メール・LINE・人・栞・Clip・記録・Hatch を、**好きな数だけ**並べる。幅は全幅か半分（半分どうしは横に並ぶ）、高さは決めるか「縦いっぱい」（見出しの歯車で編集・足す）。
    - フォルダ：ドロワーの中にフォルダの中身。端末のフォルダ（SAF）・NAS・ドライブ。場所は置いたものごとに覚え、戻るで上のフォルダへ。
    - Web ページ：リンクもその中で開き、戻るでページを戻る。画像・PDF：画像は指で拡大、PDF は縦に並べる。
    - 予定・メールなど：今までのドロワーと同じ中身。
  - **アプリのカテゴリーのタブ**：そのカテゴリーのアプリ・ショートカットと、そのアプリの通知。歯車から、アプリの上にウィジェット・フォルダ・予定なども置ける（アプリと一緒にスクロール）。
  - 0.21.0 までの専用のタブ（フォルダ・予定・メール…・ウィジェット）は、更新すると中身が 1 つのふつうのタブに移る（見た目は今までどおり）。

<img src="docs/screenshots/board-tab.png" width="320" alt="ふつうのタブ（画像を半分ずつ・フォルダ）"> <img src="docs/screenshots/board-tab-edit.png" width="320" alt="ふつうのタブの編集"> <img src="docs/screenshots/panel-board.png" width="320" alt="予定の下にメールを足したタブ">

- **タブは閉じた画面と開いた画面で共通**。ドロワーの幅（内側の端の取っ手をなぞる、2 回押すと元に戻る）とふつうのタブの中の高さだけ、画面ごとに覚える。タブを長押し →「閉じた画面だけに出す／開いた画面だけに出す」もできる（隠したタブは「＋」から戻せる）。
- **どのタブにもアプリ・ショートカットを置ける**：タブを長押し →「アプリ・ショートカットを置く」。ドロワーの上に並ぶ。
- タブの追加：端のタブの下の「＋」から、ふつうのタブ（ウィジェット・フォルダ・Web ページ・画像や PDF・予定など、中身を 1 つ入れて作る／空のタブ）とアプリのカテゴリーのタブ。**長押し→ドラッグ**で並べ替え、動かさずに離すとメニュー（上へ・下へ・名前・アプリを置く・出す画面・幅・外す）。アプリのアイコンも長押し→ドラッグで並べ替え（カテゴリーごとに覚える）。
- アプリのショートカット（LINE のトークルームなど）もタブに置ける：アプリの長押し →「ショートカット」、または各アプリの「ホーム画面に追加」（置くタブを選ぶ）。カテゴリーのタブは、長押し →「ショートカットを別の段に」でアプリと分けて並べられる。

- アプリの一覧は端のタブのいちばん下に固定の「START（ALL）」か、検索の横のボタン（Alt＋A）。仕分けたカテゴリーは、それぞれタブにもできる（アイコンのグリッド）。
- **ピン留め**：よく使うアプリ・ショートカット（8 つまで）を、端のタブの下（START の上、スクロールしても隠れない）と、すべてのアプリの上に並べる。アプリ・ショートカットの長押し →「ピン留め」、または「＋」→ PINNED で選ぶ。初めは LINE・Google の音声検索・MemoHatch の音声メモ（入っているものだけ）。音声検索・音声メモのような「機能」もピン留めできる。

- **入力**（ピン留めのペンのアイコン）：声・文字・写真で書いて、そのまま **LINE・メール・ほかへ共有・Clip** へ送る。どれを押しても先に **MemoHatch に残す**（入っていなければこのホームの Clip）。「送り先…」で並びと、LINE の決まった宛先（最近の会話から。試しの機能）を選べる。

- **思いついたらすぐ入力**：ほかのアプリの上でも、ボタン 1 つで入力の画面を開き、書いて（話して・撮って）から送り先を選ぶ。送ったら元のアプリに戻る。
  - Dimple などショートカットを置けるアプリ：このアプリのショートカット「声で入力」「文字で入力」「写真で入力」「声でアプリ」
  - モードとルーチンの「アプリを開く」：アプリの一覧の「すぐメモ」（声から。設定で隠せる）
  - 自動化アプリ：アクティビティ `jp.yaegaki.theta.home.QUICK`（extra `mode` = `voice`・`text`・`photo`）、`jp.yaegaki.theta.home.VOICE_APP`
- **予定は何日分でも**：ホームの予定は今日から 1・3・7 日分（初めは 3 日。見出しの「3D」を押すたびに切り替え）。2 日目からは日付の見出し付き。
- **区画をたたむ**：ダッシュボードの TODAY・WEATHER・FILES・DEVICE は見出しを押すとたたむ（予定は次の 1 件、天気は気温と天気・警報だけ 1 行で）。広い画面のファイラーの上の予定も、見出しの ▾ でたたむ。

- **通知を条件で絞って出す**：アプリ・含む言葉・除く言葉で決めた条件に合う通知だけを、ホームの予定と天気のあいだ（広い画面では時計の下）に出す。例：LINE の家族だけ、「至急」を含むメールだけ、「配達」を含む通知だけ。初めは LINE の通知を出す条件が 1 つ入っている（外せる）。合うものが無いときは出さない。設定の NOTICE FILTER か、区画の「FILTER ⚙」、通知の長押し「このアプリの通知をホームに出す…」で作る。「目立たせる」にした条件はアクセントの帯。

<img src="docs/screenshots/notice-filter.png" width="200" alt="条件に合う通知">

- **アプリの呼び名**：アプリの長押し →「呼び名をつける」。声でアプリを開くとき・検索で、その名前でも見つかる（いくつでも、「、」で区切る）。ピン留めの「声でアプリ」からも。

- **回線の速さ**：上の帯に下りの速さと応答時間（初めは 30 分おき、設定の NETWORK で 15・30・60 分・切る、モバイル回線では測らない設定も）。押すとすぐ測る。つながらない・遅いときは **再接続** のボタン：アプリからはモバイルデータを切り替えられないので、Galaxy のモードとルーチンなどで「モバイルデータを切って入れる」ルーチンを作り、そのショートカットを「再接続ボタン」の置き場に置くとそれを動かす。置いていなければ、Android に「つながらない」と知らせて、インターネットの切り替えパネルを開く。

- ピン留め：Fold5 メイン（690dp 以上）で 1 枚、横向きタブレット（1180dp 以上）で 2 枚、ドロワーを横に並べて出しておける。

## ファイルを中で開く

画像（JPEG・PNG・HEIC・動く GIF/WebP など）・動画・音声（ExoPlayer）・PDF・文字（txt・md・json・ソースコードなど、Shift_JIS も）・CSV/TSV（表）・zip（中身の一覧）は、ほかのアプリに切り替えずに**ホームの上のポップアップ**で開く。左右にめくると同じフォルダのほかのファイル、画像は 2 本指・2 回押しで拡大。上の「共有」「アプリで開く」で、今までどおりほかのアプリへ。NAS・Google ドライブのファイルも取得してから同じように開く。設定 → VIEWER でオフにできる。

Word・Excel・PowerPoint（docx・xlsx・pptx）は**かんたんなプレビュー**：Excel はシートごとの表（日付も読める形に）、Word は見出し・本文・箇条書き・表・画像、PowerPoint はスライドごとの文字と画像。ライブラリを足さずに中の XML を読むので、見た目どおりではない（正確には「アプリで開く」）。

**本**：マンガ（CBZ）は中で 1 ページずつ（右開き・左開きを切り替え、2 回押すと拡大）。PDF も「1枚ずつ／続けて」を切り替えられる。EPUB・CBR・M4B は **DSBooks**（0.8.7 以降）が入っていれば DSBooks で開く（DSBooks が取り込んでから開く）。PDF・CBZ も上の「DSBooks」から渡せる。

## Google ドライブ

Drive API でつなぐ（読み取りのみ、`drive.readonly`）。ファイラーの「DRIVE」から、マイドライブ・共有アイテム・共有ドライブ・スター付きを辿る。開く・共有は端末へ取得してから（Google ドキュメントなどはリンクで開く）。フォルダを長押し →「〇〇のタブにする」。

### 検索フォルダ（仮想フォルダ）

条件を保存して、合うファイルをフォルダのように出す（Google ドライブと NAS）。ドライブ・NAS の入口の「＋ 検索フォルダを作る」か、フォルダを長押し →「この中の検索フォルダを作る」。条件は種類・ファイル名・更新した時期・場所、ドライブは本文・スター付き・共有されたものも。端のタブにも割り当てられる。ドライブには初めから RECENT 7D・PDF・PHOTOS・OFFICE がある。

![](docs/screenshots/query-dialog.png)

### 初回の登録

初回だけ、自分の Google Cloud プロジェクトにこのアプリを登録する（設定 →「Google ドライブにつなぐ」に手順とリンク）：

1. プロジェクトを作る
2. Drive API を有効にする
3. Google Auth Platform：アプリ名・メール、対象は「外部」、テストユーザーに自分
4. クライアント（Android）を作る：パッケージ名 `jp.yaegaki.theta.home` と、画面に出る署名の SHA-1
5. アプリで「Google でログイン」

公開ステータスが「テスト」のままだと 1 週間ほどでログインし直しになることがある（「本番環境」にすれば避けられる。自分だけで使うなら審査は要らない）。

## NAS と Tailscale

DSBooks と同じく、Synology の DSM File Station API でつなぐ（設定 →「NAS を登録」、またはファイラーの NAS）。外出先からは Tailscale 経由のアドレス（100.x.x.x や 〇〇.ts.net）を入れる。

- 状態の表示：ネット（端末の回線）、Tailscale（VPN がオンか・未導入か）、NAS（接続・届かない・ログイン失敗・未登録）。回線が変わったときとアプリに戻ったときに調べ直す。
- つながらないときは理由を分けて案内し、「Tailscale を開く」「再接続」を出す。Tailscale を勝手にオンにはしない。VPN が無いだけで Tailscale がオフとは断定しない。
- NAS の中を辿り、開く・共有のときは端末へ取得してから渡す（取得したものは新しい 30 個だけ残す）。NAS のフォルダを長押し →「〇〇のタブにする」で、フォルダのタブに割り当てられる。
- アドレスは「100.x.x.x」のように方式とポートを省くと `http://…:5000` を補う。https（:5001）の自己署名証明書は、初回に指紋（SHA-256）を見せて信頼してもらい、以後はその 1 枚だけを受け入れる（変わったら警告）。
- 2 段階認証：求められたら 1 回だけコードを入れる。以後はデバイストークンで通る。
- パスワードは端末の鍵（Android Keystore）で暗号化して保存。
- Tailscale 経由の http を通すため、平文の通信を許可している（Tailscale の通信路自体は暗号化されている）。

## アプリの仕分け

アプリが多いときは、アプリのドロワーの「仕分け N」（N は未分類の数）か、設定の「仕分けガイドを開く」から。

1. **カテゴリーを用意**：候補（仕事・連絡・写真・カメラ・音楽・動画・ニュース・地図・移動・お金・買い物・ツール・Hatch・ゲーム・設定・端末）から選び、足りなければ自分で作る。
2. **1 つずつ振り分け**：アプリが 1 つずつ大きく出るので、振り分け先を押すと次へ進む。合うものが無ければ「＋ 新しいカテゴリー」でその場で作る。アプリの申告する種類（ゲーム・地図・写真など）や名前から、おすすめをオレンジの枠で示す。「戻す」「あとで」「ここで終わる」。

## 引っ越し（設定の書き出し・読み込み）

## もしものとき（レスキュー）

## 入れ方

1. APK を端末で開いてインストール（「提供元不明のアプリ」の許可が必要）。0.2.0 を入れていれば上書きできる（同じ鍵）。
2. まず普通のアプリとして開き、フォルダのタブにフォルダを割り当て、NAS を登録して動きを確かめる。
3. 設定 →「既定のホームにする」。

## リリース

1. 手元で `./gradlew :app:assembleRelease`（鍵は `keystore.properties`）し、APK を `releases/ThetaHomeHatch-<版>.apk` として置く
2. `releases/SHA256SUMS-<x.y.z>.txt`（`sha256sum` の出力）と `docs/release-notes/v<版>.md` を置いてコミット
3. Actions の `release-apk` を「Run workflow」で版（例 `v0.5.0-alpha`）を指定して実行するか、`v<版>` のタグをプッシュする。ハッシュ・署名の証明書・版を確かめてから Release を作り、タグも付ける。`-` 付きの版はプレリリース

## ビルド

`./gradlew :app:assembleDebug`。テスト・lint・画面の見本は `./gradlew :app:testDebugUnitTest :app:lintDebug`（見本は `app/build/screenshots/`）。リリース署名はリポジトリの外の鍵を `keystore.properties`（gitignore 済み）で渡して `./gradlew :app:assembleRelease`。**鍵と鍵の情報はコミットしない。**
